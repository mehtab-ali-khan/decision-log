## Decisions Made

- Linked the decisions with projects so they are easy to track.
- The project field on a decision is a hybrid dropdown/text input, so users can pick an existing project or type a new custom name.
- Deleting a decision always asks for confirmation first, so there are no accidental deletes.
- Search is one single search bar covering all fields to give better user experince, plus separate filters for status and project.
- The backend is faked with a dummy API layer so a real backend can be swapped in later without touching the UI.
- State is handled with plain React (useState/useReducer), no external state library for simplicity.
- Picked the stack: React, Vite, TypeScript (I would have choosed astro for landing page for better SEO if it was a seprate repo).
- Used the industry standard libraries: react-router-dom for routing, react-hot-toast for toasts, lucide-react for icons & tailwind for styling.
- All styling comes from one single theme file, nothing hardcoded in components so it is easy to change theme later.
- Landing page ui is inspired by stripe/superhuman.
- Tried to keep code as simple as possible with no extra comments, emojis, and ai generated slogans.
- The current ui for landing page and app is generated by claude opus 5, I tried claude haiku/sonnect and gpt 5.6 models, but their generated ui was very bad and old.
